Make a messy outdoor scene viewable

Ideation for the SplatAgent agent: autonomously find good angles + strip noise to the good splats — not just classify.

2026-06-29 · repo-grounded · ce-ideate · next step → ce-brainstorm one idea

The gap (grounding)

The agent already owns the right tools — navigation (orbit, capture_orbit, frame_object, look_at) and cleanup (opacity_threshold, remove_outliers, remove_needles, prune_oversized, crop_*) — but two things are missing:

1. Navigation is a means, not a goal. The system prompt uses camera moves only to grab frames for verification. There is no behavior that searches for, scores, and settles on the most legible view. "Find a good angle" is not a thing the agent tries to do.

2. Cleanup uses fixed thresholds. FLOATER_ALPHA=0.05, NEEDLE_RATIO=10, etc. are constants. On Train that left the agent with no scene-specific strategy for a capture that is 39% floaters + 32% needles — measured this session; cleanup dropped both to 0% and removed ~60% of the Gaussians as junk.

basis: backend/agent/system_prompt.py · backend/contracts/constants.py · live metrics on public/demos/train.ply

Top ideas (survivors)

#1 Autonomous best-view searchangles

Give the agent a real “find the best angle” loop: capture_orbit N candidate views around the cleaned core, score each frame for legibility (fraction of frame filled by high-opacity foreground, low sky/empty fraction, subject roughly centered), then park the camera at the winner and narrate why. Turns the camera from a verification tool into a deliverable.

Why strong Directly answers “find good angles,” and capture_orbit already exists — this is a scoring + selection step, not new rendering.

builds on: capture_orbit, set_view · new: a frame-legibility score

#2 “Denoise to subject” pipelinenoise

A named outdoor-tuned cleanup sequence whose goal is “leave only the good splats”: opacity-gate floaters → drop spatial outliers → strip needles → density-filter the sparse background haze, each verified and rolled back if it eats the subject. One coherent “make it clean” objective instead of the human guessing which buttons to press.

Why strong Answers “only good splats remain” head-on; composes tools the agent already has into the move outdoor scenes actually need.

builds on: opacity_threshold, remove_outliers, remove_needles, filterByDensity · verify via silhouette_intact

#3 Clean-first, then frame (inversion)both

Today the agent frames to inspect, then cleans. Invert it: strip the obvious noise first, so the framing math (and best-view search) sees only good splats — then compute the angle on a clean subject. This is the structural fix for “floaters throw off the framing,” which the new percentile-bounds framing only half-solves.

Why strong High-leverage glue: makes both #1 and the default load-framing robust on messy scenes for almost no new code.

builds on: this session's src/viewer/framing.ts + the cleanup tools

#4 Adaptive thresholds from the histogram valleynoise

Instead of fixed constants, the agent reads the opacity / scale histograms (now surfaced in the metrics panel) and sets each cutoff at the natural valley between the noise mode and the signal mode. A clean sphere and a 39%-floater outdoor capture get different, scene-appropriate cleaning strength.

Why strong Fixes the brittleness that makes outdoor scenes hard; grounded in the real metrics this session exposed.

builds on: Metrics.opacity.histogram / scale.histogram · replaces fixed FLOATER_ALPHA usage

#5 Multi-view-consistency floater cullingnoise

True floaters are view-inconsistent — they appear from a few angles and vanish from others. Use capture_orbit to flag splats that flicker across views and cull them. Catches structured noise that a single opacity threshold can’t, and it’s reference-free — exactly the architecture’s “multi-view self-consistency” principle.

Why strong Novel capability aligned with the project’s stated quality philosophy; removes junk fixed thresholds miss.

builds on: capture_orbit, multi-view self-consistency (ARCHITECTURE §3)

#6 “Scene legibility” as the agent’s objectiveboth

Define one legibility score (foreground fill + opacity concentration + silhouette clarity + view framing) and make the messy-scene loop optimize it: clean and reframe until legibility crosses a bar or stops improving. Gives the “make it viewable” goal a concrete, measurable target instead of vibes.

Why strong Unifies #1–#4 under a single objective; a natural fit for a metric-driven ce-optimize loop later.

composes: best-view score (#1) + cleanliness metrics (#2,#4)

#7 Auto-clean + auto-frame on loadboth

The moment a messy .ply registers, run a conservative denoise + best-view pass automatically, so the first thing the user sees is the cleaned subject at a good angle — not 60% garbage. Opt-out, reversible. Directly kills the “first impression looks terrible” problem you hit.

Why keep (quick win) Most direct fix for the pain that started this; product-level, leans on #2 + #3 once they exist.

builds on: registerScene in src/App.tsx + #2/#3

Considered & cut

  • Occluder “x-ray” culling — remove splats between camera and subject. Risky: hard to tell an occluder from real foreground reference-free; high chance of deleting the subject. Partially absorbed into #2.
  • Rule-of-thirds / aesthetic composition scoring — over-engineered; the legibility score in #1 captures the useful 80% without brittle photography heuristics.
  • Orbit “contact sheet” UI — nice presentation, but it’s a UI feature, not the agent’s core navigate/clean ability. Defer; could be how #1 surfaces its candidates.
  • Cinematic guided tour of the cleaned scene — polish, not “make it viewable.” Defer until the core loop lands.
  • Reframe-after-every-edit — real, but an implementation detail of #1/#3 rather than a standalone idea; folded in.

How they map to your ask

Find good angles → #1 (best-view search), enabled by #3 (clean-first).
Strip noise to good splats → #2 (denoise-to-subject), sharpened by #4 (adaptive thresholds) and #5 (multi-view culling).
Tie it together → #6 (legibility objective) gives the loop a target; #7 makes it the default first impression.

Recommended first brainstorm: #1 Autonomous best-view search — it’s the capability the agent most visibly lacks, it’s the half of your ask that isn’t cleanup, and it’s buildable on existing tools.
